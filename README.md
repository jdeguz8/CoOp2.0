# MyStores Demo (Google Maps + Firebase)

A simple Android demo app showing how to mark store locations on a map and save them to Firebase Firestore.

## Features
- Google Maps SDK integration
- Long-press map to add store
- Dialog prompt for store name
- Firebase Firestore backend
- Real-time snapshot updates
- MVVM architecture + Compose UI

## Tech Stack
- Kotlin
- Jetpack Compose
- Google Maps Compose
- Firebase Firestore
- ViewModel + StateFlow
